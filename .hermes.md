# Imposer

**PDF imposition tool** — arranges multiple copies of artwork onto press sheets for wide-format and litho printing. The most complex tool in the WAC toolkit.

**Live:** https://4003player.github.io/Imposer/  
**Repo:** https://github.com/4003player/Imposer.git (owner: 4003player)  
**Stack:** Single-file HTML (~3,650 lines main, ~4,070 lines v2), no build step, GH Pages hosted.

## Architecture

- **pdf-lib** (+ local `pdf-lib.min.js`) — all PDF manipulation and output
- **fontkit** — font embedding for labels/annotations
- **PDF.js** — preview rendering
- **UTIF.js** — TIFF support
- **pako** (in some flows) — stream decompression

## Versions

- `index.html` — production v1
- `v2.html` — development branch with Smart Orient, Fit-to-Layout, sheet dedup, No Back option, back label fix

## Key Features

- N-up imposition with margins (MARGIN = 0.25")
- Double-sided: same back, common back, different back per face
- Back pages rotated 180° for book-fold flip
- Die line mirroring across flip axis for backs
- CutContour / die line stripping and handling
- Spot color detection (CMYK simulation, 59+ CMYK refs)
- OPW (Opaque White) layer handling
- Mixed-orientation nesting
- Qty = cavities, printQty = remainder calculation
- Press preview at 8.5×14

## v2-Only Features

- **Smart Orient (Quadrant layout):** grouped halves, NOT checkerboard
  - Even×even = both orientations (top↑ bottom↓)
  - Even×odd = L/R only (all↑)
  - Odd×even = T/B only (all↑)
  - Odd×odd = standard
- **Fit-to-Layout** — auto-size sheet to content
- **Sheet dedup** — eliminate duplicate sheets
- **No Back option** — skip back page generation
- **`applyBleedOverride()`** → `invalidateLayout()`, skip in smartOrient

## Critical Rules

1. **`useObjectStreams: false`** — ALWAYS. Required for Caldera RIP
2. **TrimBox vs MediaBox** — `hasTrim` when diff > 0.5pt. TrimBox = material edge
3. **pdf-lib `load()` detaches ArrayBuffer** — always copy bytes first
4. **Back 180° CTM** — `ox = -(srcBl - usrBl)` for back page coordinate transform
5. **`embedPages()` needs `.slice(0)`** — pdf-lib quirk with array references
6. **Die line stripping (find-and-excise):**
   - `/CSn CS` → find first paint op: `S` = remove block; `f` = leave untouched
   - Handle bare depth-0 `S` and `q`-wrapped `S`
   - Delete die CS from Resources
   - Alert on filled die lines
   - `extractPathsForCS`: only push `S`/`B` as die paths, skip `f` (Konami has text fills on Dieline layer)
7. **`findBackSource()`** — searches BACK pages for `backRef` → face mapping
8. **`numVal()` helper** — Safari input parsing
9. **Transparent fills for cut layers** — required for Caldera cut workflow
10. **Canvas cap 4000px** max dimension

## Content Stream Parsing

- `getContents()` returns COMPRESSED data — must decompress with pako
- Coordinate ops: `v`/`y` = 4 operands (shorthand cubic Bézier)
- CS dict extraction uses raw regex on page resources
- Die CS detection: backward-scan for `/Separation` color spaces
